Desktop Client

Kiselgram Desktop is a JavaFX application for macOS and Windows. It provides a full messaging experience outside the browser.

Downloads

Get the latest version from desktop.kiselgram.ru.

macOS (Apple Silicon)

Self-contained .app bundle for M1/M2/M3/M4 Macs. Includes Java 21 runtime. No external dependencies needed.

Download (ARM64)

macOS (Intel)

Lightweight launcher for Intel Macs. Requires Java 21.

Download (Intel)

Windows

Lightweight launcher for Windows. Requires Java 21.

Download (Windows)

Features

  • Login: password, QR code, email link
  • Chat list with auto-refresh and search
  • Chat detail with bubbles, reactions, timestamps, read receipts, edited labels
  • File upload — images, audio recording, documents
  • Image preview / lightbox
  • Audio playback
  • Emoji picker
  • Reply, edit, delete, copy, save, forward messages
  • In-chat search
  • Block user / unblock
  • Pin/delete chat
  • Create/leave group, group info with member list
  • Edit profile (name, bio)
  • Global search — users, groups, channels
  • Message date separators
  • Typing indicator
  • System tray notifications
  • Stories viewer
  • Saved Messages
  • Channels — subscribe/unsubscribe
  • Settings — theme, font, bubble colors, hero image

Building from Source

The desktop client is a Gradle project in the kiselgram_desktop/ directory.

export PATH="/opt/homebrew/opt/openjdk@21/bin:$PATH"
./gradlew build   # compile + jar
./gradlew run     # launch

API Compatibility

The desktop client communicates with https://api.kiselgram.ru/api.v2/api. All API endpoints are shared with the web SPA.
