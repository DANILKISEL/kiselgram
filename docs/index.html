Tech Stack

  • Backend: Python Flask + PostgreSQL (prod) / SQLite (dev)
  • Frontend: Vanilla JS SPA (17 modules extending window.K)
  • Video calls: WebRTC via separate SocketIO server (Python)
  • Mail: docker-mailserver (Postfix/Dovecot/OpenDKIM)
  • Mail admin: Standalone Flask container at /mailadmin/
  • Desktop: Java 21 + JavaFX
  • Deployment: Docker Compose on Ubuntu 22.04 VPS
  • SSL: Let's Encrypt via certbot Docker container
