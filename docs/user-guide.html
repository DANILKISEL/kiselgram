User Guide

Registration & Login

Go to web.kiselgram.ru to register a new account or log in.

Registration methods

  • Email + password — standard registration with email verification
  • Google OAuth — sign in with your Google account
  • QR code — scan from the desktop client to link your session

Messaging

Start a chat by clicking on a contact or searching for a user. You can send text messages, images, documents, videos, and audio recordings.

Message features

  • Edit — fix a typo after sending
  • Delete — remove a message for everyone or just yourself
  • Reply — respond directly to a specific message
  • Forward — send a message to another chat
  • Pin — highlight important messages
  • React — add emoji reactions to messages
  • Read receipts — see when your message was read

Groups

Create groups to chat with multiple people at once. Group admins can add/remove members and manage group settings.

Channels

Channels are broadcast-style one-way communication. Users subscribe to channels to receive updates from the channel owner.

Stories

Share photos and videos that disappear after 24 hours. View who has seen your story and react to others' stories.

Video Calls

Start a WebRTC video call with any user. The video server runs on a separate SocketIO-based Python server.

Saved Messages

Your private cloud — send messages, files, and links here to bookmark them for later. Only you can see this chat.

Settings

Customize your experience:

  • Theme — dark/light mode
  • Font size — small, medium, large
  • Bubble colors — customize your message bubble and their message bubble colors
  • Privacy — last seen, profile photo, and online status visibility
  • Sessions — manage active sessions and log out remotely

Email on Kiselgram

Every user gets a @mail.kiselgram.ru email address. Access your email via:

  • IMAP — mail.kiselgram.ru:993 (SSL)
  • POP3 — mail.kiselgram.ru:995 (SSL)
  • SMTP — mail.kiselgram.ru:587 (STARTTLS)

Manage your email account password and settings from the Mail Admin panel.

Security

  • Bearer token authentication for API requests
  • Session management — view and revoke active sessions
  • Rate limiting on auth endpoints
  • CSP and security headers on all responses
