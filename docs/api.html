API Reference

Base URL: https://api.kiselgram.ru/api.v2/api

Authentication: Bearer token via Authorization: Bearer <token> header.

Response shape: {success: bool, data: {...}} or {success: false, error: {code, message}}

Auth

POST /auth/register

Register a new user. Body: {username, email, password}.

POST /auth/login

Log in with email/password. Body: {email, password}.

GET /auth/verify?token=<token>

Verify email with token sent via email.

POST /auth/login/google

Google OAuth login. Body: {id_token}.

Chats

GET /chat_list

Get all chats for the current user.

POST /chats/create

Create a personal chat. Body: {user_id}.

DELETE /chats/<id>

Delete a chat.

POST /mark_read/<chat_id>

Mark a chat as read.

Messages

GET /messages/<chat_id>?after=<id>&limit=50

Get messages for a chat (paginated).

POST /messages/<chat_id>

Send a message. Body: {text} or multipart for files.

PUT /messages/<id>

Edit a message. Body: {text}.

DELETE /messages/<id>

Delete a message.

POST /reaction/<message_id>

Add/remove reaction. Body: {emoji}.

POST /typing/<chat_type>/<chat_id>

Send typing indicator. Chat type: personal or group.

Groups

POST /groups/create

Create a group. Body: {name, member_ids[]}.

GET /groups/<id>

Get group info and members.

PUT /groups/<id>

Update group settings (name, photo).

POST /groups/<id>/add_member

Add member to group.

POST /groups/<id>/remove_member

Remove member from group.

Contacts

GET /contacts

Get contact list.

POST /contacts/add

Add contact. Body: {user_id}.

POST /contacts/remove

Remove contact. Body: {user_id}.

Profile

GET /profile

Get current user profile.

PUT /profile

Update profile. Body: {username, bio, name}.

POST /profile/avatar

Upload avatar (multipart file).

Stories

GET /stories

Get stories feed.

POST /stories/upload

Upload a story (multipart file).

POST /stories/<id>/view

Mark story as viewed.

POST /stories/<id>/like

Like/unlike a story.

Channels

POST /channels/create

Create a channel.

POST /channels/<id>/subscribe

Subscribe to a channel.

POST /channels/<id>/unsubscribe

Unsubscribe from a channel.

Search

GET /search?q=<query>

Global search for users, groups, channels.

Saved Messages

GET /saved_messages?limit=50

Get saved messages (cloud bookmark chat).

Sessions

GET /sessions

List active sessions.

DELETE /sessions/<id>

Revoke a session.

QR Login

POST /auth/qr/generate

Generate a QR login token. Returns {token, expires_in}.

GET /auth/qr/status/<token>

Poll QR login status. Returns session token when scanned.

POST /auth/qr/claim/<token>

Claim a QR token (scan from mobile).
